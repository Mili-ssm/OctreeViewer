Embeddable voxel viewer

This host owns the canvas and controls a Rust/WASM renderer in a dedicated worker. Open a project-format file or explore the synthetic sample.

Photogrammetric RGB cloud of a 600 × 600 m patch of the Belvedere Glacier (Macugnaga, Italy), 2009. Data: Ioli et al., Belvedere Glacier long-term monitoring Open Data, CC BY 4.0; cropped and converted for this demo.
The built-in sample is a local project file. Choose its optional matching .octattrs sidecar with the second file picker. Without the optional attribute file, geometry is gray. Reads run in the worker.

Choose a LAS/LAZ file. Conversion runs locally in a separate worker and writes to browser storage. This browser path runs the same conversion pipeline as the command-line converter, spooling intermediate data in RAM and in OPFS zones. Extra Bytes and CRS are not retained. OPFS quota and large-file performance depend on the device. Successful outputs stay in site storage; remove site data to reclaim space. Closing the tab abruptly can leave an incomplete temporary file.

Sets the finest projected voxel edge to try. The scene starts with coarse voxels and refines toward this value; if a finer step exceeds the render budget, the last complete scene stays visible. Cells share an aligned grid; gaps remain where the scan has no samples. Dynamic picks 1, 2, 4 or 8 px from the GPU frame time (frame interval when the GPU cannot time frames) and ignores the slider until you go back to Fixed.
Cells cubes are never drawn smaller than this, whatever the pixel target asks for (the larger of both wins). Missing intensity falls back to grayscale RGB; missing classification keeps RGB.
