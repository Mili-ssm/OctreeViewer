Embeddable voxel viewer

This host owns the canvas and feeds position/color buffers into the WASM module. Rust presents the synthetic point cloud through WebGPU.

Missing intensity falls back to grayscale RGB; missing classification keeps RGB.

Waiting for WebGPU…

Drag to orbit, Shift+drag to pan, scroll to zoom. Focus the canvas and use arrow keys; hold Shift to pan, use +/− to zoom, and Home to fit.
