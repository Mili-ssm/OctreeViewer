Embeddable voxel viewer

This host owns the canvas and controls a Rust/WASM renderer in a dedicated worker. Open a project-format file or explore the synthetic sample.

The built-in sample is a local v1/v2 file. Choose another project file with the keyboard-accessible file picker. Reads run in the worker.
Convert a local LAS/LAZ file Choose a LAS/LAZ file. Conversion runs locally in a separate worker and writes to browser storage. This browser path scans the LAS/LAZ twice in bounded blocks: first to plan eight spatial nodes and stratified representatives, then to write them. Extra Bytes and CRS are not retained. OPFS quota and large-file performance depend on the device. Successful outputs stay in site storage; remove site data to reclaim space. Closing the tab abruptly can leave an incomplete temporary file.

Sets the finest projected voxel edge to try. The scene starts with coarse voxels and refines toward this value; if a finer step exceeds the render budget, the last complete scene stays visible. Cells share an aligned grid; gaps remain where the scan has no samples. Missing intensity falls back to grayscale RGB; missing classification keeps RGB.
