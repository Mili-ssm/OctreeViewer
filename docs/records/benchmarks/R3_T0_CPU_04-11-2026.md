## Método y límites

Cada [comando](data/r3-t0-independent-04-11-2026/majadas-4-r1.command) tiene un archivo homónimo para su muestra. El [ejecutor](data/r3-t0-independent-04-11-2026/run.py) lanzó las nueve secuencialmente, comprobó las condiciones del probe y vigiló cada 0,5 s procesos Chrome, Chromium, Firefox, cargo y rustc ajenos; no detectó interferencias. Un proceso breve entre sondeos u otra carga no vigilada podrían escapar a esta observación. La ejecución se realizó después de finalizar `scripts/check.sh --offline`.

Cada JSON contiene un error 404 de consola. El [log HTTP completo](data/r3-t0-independent-04-11-2026/http.log) identifica nueve peticiones fallidas, todas a `/favicon.ico`, una por ejecución; se consideran ajenas a la carga del dataset. No hubo otros códigos HTTP 4xx o 5xx registrados.
