# R3 T1: diagnóstico de alternativas de profundidad — 04-11-2026

**Estado: propuesta; T1 sigue detenido.** En las 16 hojas filtradas por colisiones entre posiciones `f32` distintas al límite, el diagnóstico separa las posiciones finitas únicas continuando hasta una profundidad relativa máxima de 18. Se recomienda estudiar una continuación adaptativa hasta esa separación, sujeta al límite de 21 bits y a la aprobación del propietario. No es una decisión ni modifica las reglas aceptadas.

## Evidencia y alcance

El [diagnóstico de parada](R3_T1_STOP_04-11-2026.md) describe el dataset y el criterio de selección. El programa de esta captura recorre las hojas y filtra aquellas cuya ocupación en el límite es menor que el número de posiciones finitas únicas; las 16 hojas resultantes **no son el dataset completo**. La unicidad compara bits de coordenadas locales `f32`, normalizando el cero con signo. En esta ejecución no se contaron posiciones no finitas. La separación observada en esas 16 hojas no demuestra que no exista truncamiento en todo el dataset ni en otros datasets.

| Cadena tras poda de crecimiento 1,5 | Celdas retenidas | Payload nominal `NodeCell` (80 bytes/celda) |
| --- | ---: | ---: |
| Límite fijo | 17.373 | 1.389.840 bytes |
| Continuación hasta separar posiciones únicas | 18.553 | 1.484.240 bytes |
| Diferencia | +1.180 | +94.400 bytes |

Estas cifras son solo el producto nominal del número de celdas por el tamaño de `NodeCell`; no miden memoria real, tiempo ni GPU, ni establecen causalidad de rendimiento. La profundidad relativa se mide desde `node_base` según el [fuente](data/r3-t1-options-04-11-2026/src/main.rs); el máximo observado es 18, dentro del rango explorado de 21 bits.

## Alternativas y trabajo pendiente

| Alternativa | Consecuencia y cuestión pendiente |
| --- | --- |
| Mantener el límite fijo | Conserva el límite actual, pero las colisiones distintas mantienen activada la parada. |
| Aumentar el límite fijo | Puede separar estos casos, pero no garantiza separación general ni demuestra un coste aceptable. |
| Continuar adaptativamente hasta separar las posiciones finitas únicas | Recomendación para estudiar: evita continuar cuando ya existe separación; requiere definir el comportamiento al agotar los 21 bits y obtener aprobación antes de cambiar las reglas aceptadas. |

Antes de decidir: comprobar casos sintéticos de duplicados, no finitos y posiciones distintas inseparables en 21 bits; comprobar determinismo y límites de recursos; medir datasets completos con comparaciones repetidas de tiempo, memoria y GPU/navegador bajo condiciones comparables. La captura actual no valida una implementación de producción.
